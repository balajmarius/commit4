# COMMIT 4

Digital LCD mini-game.

### Setup

Use Node.js 20.19+ or 22.12+ (see `engines` in `package.json`).

```bash
npm install
```

### Development

```bash
npm start
```

Vite serves the app at http://localhost:5173. `npm run dev` is an alias.

### Code style

```bash
npm run check
npm run lint:fix
npm run format
```

### Production

```bash
npm run build
npm run preview
```
